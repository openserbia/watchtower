# Transitive security floors.
#
# code-review-graph constrains its deps loosely (e.g. `mcp<2,>=1.0.0`), so pip is
# free to keep an already-installed version that carries a known advisory: a plain
# `pip install -r requirements.txt` upgrades nothing that already satisfies the
# range. These floors make the fixed versions a hard requirement, so a venv
# created before the fix converges instead of silently failing the snyk gate in
# .githooks/pre-commit.
#
# Each floor names the advisory it closes. Drop an entry once code-review-graph
# (or its own deps) requires that version or newer on its own — `task
# security:snyk:deps` re-flags it if a floor is removed too early.
